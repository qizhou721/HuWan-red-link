# 地图地理比例调整

地图改为真实省界与统一墨卡托投影。经度和投影后的纬度使用同一个缩放系数，SVG保持等比例显示。地名的引线和文字位置不改变节点坐标。地图包含经纬网及中部纬度附近的约100公里比例尺。

节点连线只表达历史节点的先后关系，不是道路、逐日行军轨迹或完整途经地点。底图为现代行政省界，服务于课堂地理理解。地点按所在地区近似标注，不能用作旧址导航。

## 数据来源

- 省界：DataV.GeoAtlas，来源为高德开放平台，2021年5月版，仅用于学习交流。原始接口：https://geo.datav.aliyun.com/areas_v3/bound/100000_full.json 。边界在本地裁剪、简化后嵌入网页，无需运行时联网。
- 何家冲：https://www.amap.com/place/B017802FLQ 。
- 独树镇：https://ditu.amap.com/place/B01790QECH 。
- 沣峪口：https://www.amap.com/place/B001D085EZ 。
- 永坪：https://www.amap.com/place/B038F0NIVB 。
- 永宁镇：https://www.openstreetmap.org/node/3480558966 ，© OpenStreetMap贡献者，ODbL，按永宁镇附近定位永宁山。
- 两当、秦安、静宁、隆德、泾川、华亭、商州：DataV.GeoAtlas相应县区接口的`properties.center`。
- 庾岭镇范围：丹凤县政府《庾岭镇土地利用总体规划（2006—2020年）调整完善》，东经110°20′30″至110°32′50″、北纬33°48′23″至33°57′，取镇域范围中心作近似定位。
