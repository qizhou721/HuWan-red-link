# 沪皖红联 · 少年长征记

红二十五军长征路线与科创营节点成果展示原型。参加人数81人，最终小组数量、教学节点与游戏形式待定；每组对应一个教学节点。

本项目使用独立仓库 `qizhou721/HuWan-red-link`，通过GitHub Actions发布 `dist/` 到GitHub Pages。

## 当前能力

- 红二十五军主要节点路线示意，真实省界与统一经纬度投影，附资料来源；部分小地点按所在县镇近似标注。
- 节点历史文字与小组图文、视频分开查看。
- 管理入口演示节点关联、媒体上传、草稿与发布、撤回。
- 管理数据只保存在当前浏览器的IndexedDB，不会自动同步给家长或其他访客。
- 可导出只含已发布内容和对应媒体的观看HTML。管理员可将导出文件更新为`dist/index.html`，由Pages再次发布，所有访客即可查看该内容快照。导出的文件不显示老师入口。

## 正式管理功能

当前教师入口为流程演示，并非管理员身份验证。正式跨设备上传需要另外接入管理员登录及共享数据、媒体存储。GitHub Pages负责静态网页托管。

页面无外部JavaScript、字体或媒体依赖。手机与电脑均有适配；地图连接线表示主要节点先后关系，不是精确道路或全部途经地点。

通过15项核心逻辑检查，覆盖一组一节点、草稿与发布隔离、媒体内容发布、撤回和导出排除草稿，以及地图比例、方向、范围和旧内容保留。地图数据与近似定位说明见[docs/geography.md](docs/geography.md)。浏览器真实文件上传与视频播放仍需实际设备验证。
